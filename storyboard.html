Storyboard

Storyboard is a work-in-progress real-time 3D game engine I am developing in C with Vulkan. The project is intended to provide a foundation for creating and animating interactive 3D scenes.

Project goals

The engine is being designed around low-level GPU access and a modular architecture. Planned capabilities include lighting, shadows, texture mapping, and support for Windows and Linux.

C provides the performance and low-level control needed for this work, while Vulkan is the rendering API.
