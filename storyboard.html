Storyboard

Storyboard is an experimental 3D graphics project written in C. Its source explores mesh loading, vector and triangle operations, camera projection, and a GLFW-driven render loop. The current executable path is an OpenGL prototype; the linked repository does not contain a Vulkan renderer despite the earlier card description.

Geometry and OBJ import

The source defines vector, triangle, camera, projection, and object structures. The OBJ loader reads vertex records and triangular faces, converts the OBJ's one-based vertex indices to zero-based indices, expands faces into triangle structures, and assigns colours from a repeating six-colour palette. The current importer is intentionally narrow: it handles triangle faces, while texture-coordinate and normal data are not yet assembled into a rendered material pipeline.

Camera and projection experiments

The camera header contains helpers for rotating vertices and triangles, computing triangle normals, performing perspective projection, and sorting projected triangles by average depth. The camera configuration uses a 70° field of view, a 5-unit near plane, and a 1000-unit far plane. The model setup places the loaded object at z = 15.

The frame function currently leaves the rotation, perspective transform, and depth-sort calls commented out. Instead, it clears the framebuffer and draws a fixed 2D test triangle. The declared 3D pipeline is therefore a set of in-progress components, not the active frame-by-frame rendering path.

Window and graphics path

The entry point creates a 640 × 480 GLFW window, requests an OpenGL 3.3 Core Profile context, updates the viewport to the framebuffer size, and calls the project's initialization and frame functions until Escape closes the window. The Makefile links OpenGL and GLFW-related libraries on a Unix-like platform.

The repository also contains GLSL 4.60 vertex and fragment examples, but the Makefile and current frame path do not compile or load those files. In addition, the draw helper uses legacy immediate-mode calls while the window requests a Core Profile context. These parallel experiments make the repository useful for tracing the evolution of the renderer, but the graphics path needs consolidation before it can serve as a reliable engine foundation.

Current scope

Storyboard is an early graphics-engine prototype, not a finished game engine. The checked-in code does not currently provide a complete interactive 3D scene, production lighting, shadows, texture mapping, a Vulkan backend, or a demonstrated cross-platform release.
